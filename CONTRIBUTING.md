## How to contribute

1. Fork the repository and create a branch from `trunk`.
2. Make your changes and ensure `dotnet build` and `dotnet test` pass cleanly.
3. Open a pull request. Your PR description should explain *what* the change
   does and *why* it is needed.
4. By opening the PR you are agreeing to the CLA terms above.
